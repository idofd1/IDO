# Discord Bot

A feature-rich Discord bot with multiple commands and functionalities.

## Setup

1. Clone this repository
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env` and fill in your bot token and MongoDB URI
4. Start the bot: `npm start`

## Available Commands

- !help - Shows all available commands
- !players - Shows list of players on FiveM server
- !status - Check server status
- !staff - Shows online staff members
- !ticket - Create a support ticket
- (More commands as implemented)
